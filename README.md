## 📋 Sobre o Projeto

Portfólio pessoal desenvolvido do zero com **HTML5, CSS3 e JavaScript puro** — sem frameworks, sem dependências. Design dark-mode moderno com animações fluidas, cursor customizado e partículas interativas.

> **Live demo:** [robsonsilva243.github.io/Portfolio-Robson](https://robsonsilva243.github.io/Portfolio-Robson)

---

## ✨ Funcionalidades

- **Cursor customizado** com efeito de lag suave
- **Canvas de partículas** interativas com conexões dinâmicas
- **Typing effect** com múltiplas frases rotativas
- **Parallax** nos orbs de fundo ao rolar a página
- **Scroll reveal** com animações de entrada por direção
- **Skill bars** animadas ativadas por IntersectionObserver
- **Contadores** animados (projetos e tecnologias)
- **Header** com efeito glassmorphism ao rolar
- **Menu mobile** responsivo com overlay
- **Formulário de contato** com validação e feedback visual
- **Scroll to top** com botão flutuante
- Design **100% responsivo** (mobile-first)
